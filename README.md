# Habit Tracker — Трекер привычек

> Прогрессивное веб-приложение (PWA) для отслеживания ежедневных привычек, серий (streak) и ежемесячной статистики без серверной части и регистрации.

## 🌟 Основные возможности

- **Ежедневные отметки**:
  - Быстрая отметка выполнения одним касанием с анимацией.
  - Автоматический подсчёт выполненных привычек за день («Выполнено X из Y») и прогресс-бар.
  - Выполненные привычки визуально приглушаются и автоматически опускаются вниз списка на сегодня.
  - Конфетти при выполнении всех запланированных на день привычек.

- **Управление привычками**:
  - Создание до 20 привычек: название (1–40 символов), эмодзи-иконка, выбор из 8 цветов палитры.
  - Гибкое расписание: «Каждый день» или выбранные дни недели (Пн–Вс).
  - Редактирование параметров и безопасное удаление с подтверждением.
  - Ручная сортировка списка (стрелки перемещения и Drag-and-Drop).

- **Статистика и календарь**:
  - Интерактивный календарь текущего и прошлых/будущих месяцев.
  - Возможность проставлять и снимать отметки за прошедшие даты прямо из календаря с мгновенным пересчётом.
  - Защита от отметок на будущие даты.
  - Подсчёт **текущей серии** (не прерывается в незапланированные дни), **рекордной серии** и **процента выполнения за последние 30 применимых дней**.

- **Автономность и PWA**:
  - Сервис-воркер (`vite-plugin-pwa`) для 100% автономной работы без интернета (офлайн-режим).
  - Баннер установки приложения на главный экран мобильного устройства или десктопа.
  - Индикатор отсутствия сети в шапке приложения.

- **Хранение данных**:
  - Все данные сохраняются локально в **IndexedDB** (`idb`).
  - Полный экспорт базы данных в файл JSON (`habit-tracker-backup-YYYY-MM-DD.json`).
  - Импорт JSON-файла с валидацией схемы и подтверждением перезаписи.

- **Интерфейс и доступность**:
  - Mobile-first адаптивный дизайн (от 320 px без горизонтальной прокрутки).
  - Светлая и тёмная темы оформления + поддержка системных настроек.
  - Сенсорные области от 44×44 px для удобного управления пальцем.

## 🛠 Технологический стек

- **Фреймворк:** React 19 + TypeScript
- **Сборщик:** Vite 6
- **Стилизация:** Tailwind CSS 4
- **Локальная база данных:** IndexedDB (через обёртку `idb`)
- **PWA:** `vite-plugin-pwa` + Workbox
- **Иконки:** `lucide-react`
- **Тестирование:** Vitest

## 🚀 Быстрый старт

### Требования
- Node.js 18+
- npm или yarn / pnpm / bun

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на порту [http://localhost:3000](http://localhost:3000).

### Запуск тестов

Для запуска unit-тестов функций расчёта серий, високосных годов и границ месяцев:

```bash
npm test
```

### Сборка для продакшена

```bash
npm run build
```

Результат сборки находится в директории `dist/`.

## 📊 Модель данных (Схема v1)

```json
{
  "version": 1,
  "habits": [
    {
      "id": "c62a5b6f-870b-4f9e-a89e-2938a16db322",
      "title": "Читать 20 страниц",
      "emoji": "📖",
      "color": "#3B82F6",
      "schedule": [1, 2, 3, 4, 5, 6, 7],
      "order": 0,
      "createdAt": "2026-09-01",
      "completions": ["2026-09-01", "2026-09-02", "2026-09-04"]
    }
  ]
}
```

- `schedule` — массив дней недели (`1` = Понедельник, ..., `7` = Воскресенье).
- `completions` — отсортированный массив дат в формате `YYYY-MM-DD`.
- `version` — версия схемы для валидации при импорте.
